# No Smear

Your favorite junk-drawer marker, now as a font!

I lied, it smears.

Try it out at [nosmear.kowalski.io](https://nosmear.kowalski.io).

Every character has five variations that rotate as you type, so the same letter never looks the same twice in a row. Turn on `ss01` if you want it smeared.

```css
@font-face {
  font-family: "No Smear";
  src: url("NoSmear.woff2") format("woff2");
}

.label {
  font-family: "No Smear";
  font-feature-settings: "ss01";
}
```
